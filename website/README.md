# Censor Quick website

The SvelteKit product website for Censor Quick. It uses the Vercel adapter and is deployed from this directory in the GitHub repository.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The GitHub-connected Vercel project is `censor-quick`, tracks `main` in `manvankaliber/censor-quick`, and uses `website/` as its root directory. The production domain is `censor-quick.vercel.app`.
