# Censor Quick website

The SvelteKit product website for Censor Quick. It uses the Vercel adapter and is deployed from this directory in the GitHub repository.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

In Vercel, connect `manvankaliber/censor-quick` and set the project root directory to `website`. The production domain is `censor-quick.vercel.app`.
